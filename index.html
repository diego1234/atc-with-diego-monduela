What this lesson is built from

Every term, translation, vehicle name and action below is taken from the source document, in the order it appears there. Nothing has been replaced with generic content, and no pairing has been silently corrected. Signs and markings have been verified against the FAA Aeronautical Information Manual, Chapter 2, Section 3; where a printed vehicle pairing is not the standard ground-support function, the printed wording is kept in these tables and the activity answer keys use the standard function with a review note for the tutor.

Source: the attached Word document — the section headed “Ground movements” and the vehicle table that follows it. The document is numbered “3” internally, so it is an extract of a larger teaching document.
Illustrations: the file contains no embedded images, so every sign drawing in this lesson is a labelled schematic created for it. None of them is a photograph of real airport signage.

How to work through it

Parts 1 and 2 reproduce the document. Five activities then drill it. An ATC dictionary adds extra vocabulary beyond the document, with a drill of its own, and a final test covers the source material. Dictionary entries outside the source are labelled as additional vocabulary. Any item marked Check this terminology or Instructor review required is one the tutor should review with you. The tables always show the pairing exactly as printed; where the printed pairing is not the standard function (for example the flat-bed truck), the activity answer key uses the standard function and the printed wording appears next to it with the reason and a source for the tutor.
