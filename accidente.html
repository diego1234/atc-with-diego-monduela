03

Gramática inglesa

Tres tiempos verbales con ejemplos del contexto aeronáutico y preguntas de comprobación. Las explicaciones están en español.

A

Present simple

Se usa para hechos, hábitos y rutinas.

Pilots communicate with controllers.

Los pilotos se comunican con los controladores.

Controllers monitor aircraft.

Los controladores supervisan las aeronaves.

The aircraft maintains its altitude.

La aeronave mantiene su altitud.

Pilots follow instructions.

Los pilotos siguen las instrucciones.

B

Past simple

Se usa para acciones terminadas en el pasado.

The pilot reported an emergency.

El piloto declaró una emergencia.

The aircraft descended rapidly.

La aeronave descendió rápidamente.

The controller acknowledged the message.

El controlador confirmó la recepción del mensaje.

The crew experienced an overspeed condition.

La tripulación experimentó una condición de exceso de velocidad.

C

Present perfect

Se forma con have / has + participio pasivo. Conecta una acción pasada con el momento presente.

The pilot has reported an emergency.

El piloto ha declarado una emergencia.

The aircraft has descended rapidly.

La aeronave ha descendido rápidamente.

The controller has received the message.

El controlador ha recibido el mensaje.

The crew has experienced a serious problem.

La tripulación ha experimentado un problema grave.

The pilot reported an emergency. → El piloto declaró una emergencia (en un momento concreto del pasado).

The pilot has reported an emergency. → El piloto ha declarado una emergencia (ya ocurrió y ahora importa: el controlador tiene la información).

El past simple mira el momento terminado. El present perfect mira el resultado en el presente. No decimos «has reported» con una hora concreta como «at 00:22».

05

El tercer condicional

Sirve para imaginar un pasado distinto. Aquí se aplica a situaciones hipotéticas de aviación, no a conclusiones sobre la emergencia real.

If + past perfect → would / might / could have + past participle
1

If the pilot had identified the problem earlier, he might have had more time to react.

Si el piloto hubiera identificado el problema antes, podría haber tenido más tiempo para reaccionar.

2

If the aircraft had maintained a safe speed, it might have avoided the overspeed condition.

Si la aeronave hubiera mantenido una velocidad segura, podría haber evitado la condición de exceso de velocidad.

3

If the controller had received more information, they could have coordinated additional assistance.

Si el controlador hubiera recibido más información, podría haber coordinado ayuda adicional.

4

If the crew had recognized the situation sooner, they might have responded differently.

Si la tripulación hubiera reconocido la situación antes, podría haber reaccionado de otra manera.

5

If the pilot had requested help earlier, the controller might have been able to respond sooner.

Si el piloto hubiera solicitado ayuda antes, el controlador podría haber respondido antes.
